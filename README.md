# frontier_model_easy_train

## 项目憧憬
轻松读懂并复现训练多个前沿AI模型

## 项目模型
| 项目名称 | 项目类型 | 详细注释 | 项目精简化重写 | 项目精简化可开启训练
|------|----------|------|
| 中文注释 | ✅ | 支持 |
| 多卡训练 | ✅ | DDP 分布式 |
| 混合精度 | ✅ | FP16 |
| 推理部署 | ❌ | 暂未实现 |
| 预训练权重 | ✅ | SigLIP 官方权重 |

## 项目优势
1. 对前沿AI模型项目的训练/推理原代码进行详细注释
2. 对该项目进行重写，不修改核心原理的基础上精简化代码，更容易学习和单卡训练
3. 增加相关知识点注释
4. 列出相关参考资料
