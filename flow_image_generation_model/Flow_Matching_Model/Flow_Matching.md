# Flow Matching Model

## 项目概述

将源分布（高斯噪声）沿时间 t 从 0 到 1 平滑传输到目标分布（真实数据），模型学习的是这条传输路径上的速度方向。

## 训练过程

**数据处理**：
- 数据集为 CelebA 对齐人脸图像，通过 Resize → CenterCrop → ToTensor 预处理
- 图像像素归一化至 [-1, 1] 范围（`img * 2.0 - 1.0`）

**数据在模型中的流程**：
1. 从数据集采样真实图像 z（即 x_1）
2. 采样噪声 x_0 ~ N(0, I)
3. 采样时间 t（默认使用 EDM 偏向 t≈1 的 skewed 采样），也可以采用平均间隔采样时间t
4. 按条件最优传输路径构建中间态：`x_t = t · z + (1-t) · x_0`
5. 计算速度标签：`u_target = z - x_0`（即 dx_t/dt）
6. 模型预测：`pred_v = UNet(x_t, t)`
7. 损失：`MSE(pred_v, u_target)`

**训练目标与损失函数**：
- 损失函数为 MSE Loss，训练目标是让模型预测的条件向量场逼近最优传输路径的真实速度 `dx_t/dt = x_1 - x_0`
- 对应论文中的 Conditional Optimal Transport（CondOT）路径：α_t = t, σ_t = 1-t

## 推理过程

- **推理流程**：
  1. 从标准高斯采样初始噪声：`x ~ N(0, I)`，形状为 (n_samples, 3, H, W)
  2. 构建 EDM 时间离散序列（ρ=7, σ_min=0.002, σ_max=80），也可以构建等差序列，得到递增的 t 序列从 ~0 到 1。
  3. 欧拉法逐步求解 ODE：`x = x + v_t(x, t) · dt`，共 flow_steps=200 步
  5. 最终输出 clamp 至 [-1, 1]，反归一化得到生成图像
