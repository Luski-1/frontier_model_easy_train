| 操作              | 改变底层数据？ | 要求连续内存？         | 结果是否连续？   |        时间复杂度      | 典型用途 |
| -------- | --------------       | ----------        | -----------           | ---------     | ------------------ |
| `view` | ❌ 否 | ✅ 必须连续 | 是 | O(1) | 确定连续时的快速变形 |
| `reshape` | 必要时拷贝 | ❌ 不强制 | 是，底层就是.continguous().view() | O(1)或O(N) | 通用变形，自动处理不连续 |
| `permute` | ❌ 否 | ❌ 不要求 | ❌ 通常不连续 | O(1) | 逻辑重排维度（如NCHW→NHWC） |
| `transpose` | ❌ 否 | ❌ 不要求 | ❌ 通常不连续 | O(1) | 交换两个维度 |

- view：要求严格（必须连续），零开销，重新计算stride
- reshape：可能拷贝，重新计算stride
- permute：交换stride中某些维度
- transpose：交换stride中某些维度

```python
# 内存连续性指的是：能否用规则的步长（strides）从1D内存中按行优先顺序读取数据，而不是指数据在内存中的真实连续性
x = torch.arange(24).reshape(2, 3, 4)  # 连续
# x[0, 0, :] =  0,  1,  2,  3   ← 物理上紧挨着
# x[0, 1, :] =  4,  5,  6,  7   ← 物理上紧挨着
# x[0, 2, :] =  8,  9, 10, 11
# x[1, 0, :] = 12, 13, 14, 15
# x[1, 1, :] = 16, 17, 18, 19
# x[1, 2, :] = 20, 21, 22, 23

# strides=(12, 4, 1)：

# 沿 dim0（第0维）走一步：从 x[0,...] 到 x[1,...]，物理跳了 12 格 ✅ = 一个子块（3×4=12个元素）
# 沿 dim1（第1维）走一步：从 x[0,0,:] 到 x[0,1,:]，物理跳了 4 格 ✅ = 一行（4个元素）
# 沿 dim2（第2维）走一步：从 x[0,0,0] 到 x[0,0,1]，物理跳了 1 格 ✅ = 相邻

y = x.permute(0, 2, 1)  # shape=(2, 4, 3), strides=(12, 1, 4)
# y[0, 0, :]  = 0, 4, 8      ← 物理上间隔4，不相邻！
# y[0, 1, :]  = 1, 5, 9      ← 物理上间隔4，不相邻！
# y[0, 2, :]  = 2, 6, 10
# y[0, 3, :]  = 3, 7, 11
# y[1, 0, :]  = 12, 16, 20   ← 物理上间隔4，不相邻！
```

```python
# permute改变了strides，但不移动内存中的实际数据位置，只是改变了"如何解释"这些数据的索引方式
y = x.permute(0, 2, 1)                  # 形状(2,4,3)
print(y.is_contiguous())                # False！不连续了
print(y.stride())                       # (12, 1, 4)  -> 非标准步长
x = torch.randn(2, 3, 4)                # 连续内存，shape=(2,3,4), strides=(12, 4, 1)
y = x.permute(0, 2, 1)                  # shape=(2,4,3), strides=(12, 1, 4)

# 访问 y[0, 1, 2]：
# 物理地址 = 基地址 + 0*12 + 1*1 + 2*4 = 基地址 + 9
# 虽然逻辑上"不连续"，但CPU/GPU可以通过strides直接计算偏移量访问

print(y[0, 1, 2])                       # ✅ 完全正常工作！
print(y + 1)                            # ✅ element-wise操作正常（通过strides遍历）
print(y * 2)                            # ✅ 数学运算正常
y.numpy()                               # ❌ NumPy转换通常需要连续（或产生拷贝）
```
