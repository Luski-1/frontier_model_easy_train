# 数据解读（由AI生成）
- 总数据步数：`2336736`（所有交互步骤的总数）
- 总回合数：`18685`（机器人推箱子的独立任务回合数）
- 数据格式：**按「总步数」连续存储**，用元数据字段划分回合/步骤

---

### 1. `ep_len`
- 维度：`(18685,)` int32
- 含义：**每个回合的总步数**
- 维度解释：18685个数字，每个数字 = 第N个回合有多少步
- 代码作用：`dataset.py`中判断回合长度是否足够采样（`length >= span`）
### 2. `ep_offset`
- 维度：`(18685,)` int64
- 含义：**每个回合在总数据中的起始索引**
- 维度解释：18685个数字，每个数字 = 第N个回合从总步数的第几位开始
- 代码作用：`dataset.py`中快速定位回合数据的起始位置
### 3. `episode_idx`
- 维度：`(2336736,)` int64
- 含义：**每一步对应的回合编号**
- 维度解释：233万+个数字，标记每一步属于第几个回合
### 4. `step_idx`
- 维度：`(2336736,)` int64
- 含义：**每一步在自身回合内的索引**
- 维度解释：从0开始递增，标记这是回合内的第几步
### 5. `action` ✅（你最关心的核心字段）
- 维度：`(2336736, 2)` float32
- 含义：**机器人单步动作向量**（PushT任务：末端执行器的X/Y位移）
- 维度解释：
  - 第1位：总步数
  - 第2位：**单步动作维度 = 2**
- 代码关联：
  ```python
  effective_act_dim = frameskip(5) * action_dim(2) = 10
  ```
### 6. `pixels`
- 维度：`(2336736, 224, 224, 3)` uint8
- 含义：**机器人视角的RGB图像**（环境观测）
- 维度解释：
  - 总步数 × 图像高度(224) × 图像宽度(224) × RGB通道(3)
- 代码处理：`dataset.py`中会`permute(0,3,1,2)` → 转为PyTorch标准格式 `(T, 3, 224, 224)`
- 配置对应：`img_size=224`
### 7. `proprio`
- 维度：`(2336736, 4)` float32
- 含义：**机器人本体感知状态**（自身关节/位置信息）
- 维度解释：单步本体特征 = 4维
### 8. `state`
- 维度：`(2336736, 7)` float32
- 含义：**环境全局状态**（箱子位置、目标位置等完整状态信息）
- 维度解释：单步全局状态 = 7维
